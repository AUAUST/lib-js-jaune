# Discarded solutions

- type-fest: `Writable` for the Color channels — toolkit's `Writable` covers it
- in-domain import cycle: keep `instanceof Color` in `parseColor` and `type` — structure check rejects the cycle
- CSS hue-rotate filter matrix: hue rotation — clips channels and shifts saturation and lightness; HSL rotation is exact and reversible
- single reference space storage: wide-gamut color model — float drift on hex round trips, conversion on every channel read
- extended sRGB float storage: wide-gamut color model — out-of-gamut colors become negative channels, hue ops stay RGB-bound
- chroma-js: color math engine — sRGB-centred, weak wide-gamut support
- tinycolor2: color math engine — 8-bit sRGB, same limits as today
- culori: color math engine — allocates an object per conversion, unfit for per-pixel producers
- colorjs.io: color math engine — pre-1.0, one large core, allocating conversions
- space id string with a global registry: `Color.space` — a record of an unloaded space fails at conversion; the record carries its `ColorSpace` instead
- Color class as data holder: color record — a frozen plain record needs no prototype or brand
- fixed set of compact color types: per-pixel output — no extension point; `ColorEncoding` contract with built-ins instead
- hand-frozen space literals in constants.ts: built-in color spaces — user: spaces are not constants; pure constants cannot call `createSpace` and methods fail readonly-constants
- custom `spaces.ts` role: built-in color spaces — new jaune-only role where the existing ports/adapters roles fit
- confined constants role: defaults built from spaces (`mixSpace`, `contrastBackdrop`) — needs an upstream engrenage change; user chose adapters as signature defaults
- custom `defaults.ts` role: defaults built from spaces — new jaune-only role; user chose adapters as signature defaults and private util tables
- shared no-gamut guard helper: `clipCoordsToGamut`/`mapCoordsToGamut` jscpd twin — a three-line guard on a shared signature; a helper adds indirection, no gain
- createRgbSpace factory: RGB transfer-loop duplication — sRGB's base is srgbLinear without a matrix, so the factory fits four of five spaces; `transferChannels` util covers all five
- polar conversion kernels: lch/oklch duplication — leave the chroma channel, hue channel and `isAchromatic` repeated; `createPolarSpace` owns them all
